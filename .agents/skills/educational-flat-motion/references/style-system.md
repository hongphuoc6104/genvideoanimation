# Style System

## Core aesthetic
- Flat vector
- Geometric construction
- Strong silhouette readability
- Controlled vibrant color
- Minimal outlines
- Layered depth
- Simple forms with expressive posing
- Infographic clarity

## Palette
Use named semantic tokens, not arbitrary colors scattered through components.
Example groups:
- background.dark
- background.mid
- accent.primary
- accent.secondary
- warm.highlight
- cool.highlight
- character.skin/fur/base
- character.shadow
- semantic.success/warning/danger

Keep a scene to a constrained palette unless narrative contrast requires expansion.

## Shape language
Prefer circles, rounded rectangles, tapered paths, smooth blobs, simple polygons.
Avoid excessive detail that does not survive motion.

## Depth
Use 3–5 meaningful planes:
- far background
- background
- subject plane
- foreground
- overlay/effects

Movement should produce coherent parallax.

## Typography
Use concise labels and high-contrast type.
Text should support visuals, not substitute for them.

## Originality
Generate original visual metaphors and character forms per production.
Do not trace or recreate reference frames.
