# Quality Rubric

Score each category 0–5.

## 1. Story clarity
0 confusing / 5 visual narrative is instantly understandable

## 2. Composition
0 cluttered / 5 clear focal hierarchy and strong silhouettes

## 3. Character acting
0 object translation / 5 convincing intent, anticipation, overlap, settle

## 4. Motion timing
0 linear/generic / 5 intentional timing and spacing

## 5. Camera
0 arbitrary/static / 5 motivated, subtle, supports narrative

## 6. Transitions
0 fades between slides / 5 motivated transformation and continuity

## 7. Secondary motion
0 none / 5 controlled life and follow-through

## 8. Visual consistency
0 inconsistent / 5 coherent design system

## 9. Information readability
0 confusing / 5 easy to follow at normal playback speed

## 10. Originality
0 derivative/copy-like / 5 original visual metaphors and assets

### Pass criteria
- no category below 3
- average >= 4.0 for premium output
- Character acting, Timing, Transitions cannot be compensated by particles or decorative effects
