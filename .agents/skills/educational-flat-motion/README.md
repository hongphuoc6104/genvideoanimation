# Educational Flat Motion Skill

A reusable agent skill for producing original 2D educational explainer videos with Remotion.

The skill focuses on production discipline rather than one-off prompting:
- story beats
- visual metaphors
- design system
- character rigging
- motion grammar
- camera choreography
- motivated transitions
- render QA
- batch production

It intentionally avoids copying specific studio assets or proprietary visual identity.

## Suggested use
Install/copy this folder into the agent environment's skill directory, then instruct the main agent to use the skill as Director and delegate implementation to coding sub-agents.

Use existing `remotion-best-practices` alongside this skill. This skill governs creative production and QA; the Remotion skill governs framework correctness.
